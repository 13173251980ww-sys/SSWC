丧尸围城｜3D 动作塔防游戏

技术栈： Unity 2022.3、C#、UGUI、TextMeshPro、Animator、NavMesh、LitJson

项目介绍： 基于 Unity 开发的单机动作塔防游戏，玩家通过角色攻击与建造、升级炮塔抵御多波丧尸进攻，保护核心建筑。包含角色解锁、关卡选择、战斗结算及本地存档等功能。

主要实现：

角色战斗与敌人行为： 使用 Animator 参数、动画分层及动画事件衔接移动、翻滚、攻击等行为；结合 NavMeshAgent 实现丧尸寻路与接近目标后的攻击，通过射线和范围检测完成伤害判定，复用 NonAlloc 查询结果数组，减少检测过程中的临时数组分配。

炮塔建造与升级： 根据配置实现炮塔建造、金币扣费与升级替换，支持单体和范围攻击；通过 Quaternion 插值实现单体炮塔转向，并结合朝向角度与攻击间隔控制开火。

关卡流程管理： 实现多刷怪点的波次生成，支持配置首波延迟、波次间隔及单只怪物生成间隔；结合剩余波次、存活怪物数量与核心建筑血量完成胜负判断，衔接奖励结算及返回菜单流程。

UI 与代码组织： 基于 BasePanel 与 UIManager 封装泛型面板访问、实例管理及 CanvasGroup 淡入淡出，完成选角、选关、战斗 HUD 和结算界面；使用异步场景加载衔接关卡初始化，并按公共组件、数据及业务功能统一目录与命名空间。

配置与数据持久化： 使用 JSON 与 LitJson 加载角色、怪物、炮塔和关卡配置，通过配置中的资源路径加载预制体与表现资源；封装本地数据读写，保存金币、角色解锁状态及音频设置。
